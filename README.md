# Controle de Ferramentas - Vercel Deployment

Sistema de controle de ferramentas em tempo real, convertido de Streamlit para Next.js.

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

## Build para Produção

```bash
npm run build
npm start
```

## Deploy no Vercel

Este projeto está configurado para deploy no Vercel. Basta conectar o repositório ao Vercel e o deploy será automático.
